Objetivo do Projeto

Desenvolver uma solução IoT ponta a ponta capaz de coletar dados ambientais (temperatura, umidade e qualidade do ar) através de um microcontrolador ESP32, transmitir as informações em tempo real via MQTT e exibi-las em uma página Web interativa com navegação e identificação do grupo.

Hardware Utilizado

  • Microcontrolador ESP32 Dev Module
  • Sensor DHT11 (Temperatura e Umidade – GPIO 14)
  • Sensor MQ-135 (Qualidade do Ar – GPIO analógico)
  • 3 LEDs de alerta físico (Temperatura, Umidade e Gás)

Arquitetura

O ESP32 lê os sensores a cada 3 segundos e publica os dados no broker Mosquitto (porta 1883). A página web se conecta via WebSockets (porta 9001) usando a biblioteca Paho MQTT e atualiza os cards em tempo real.
